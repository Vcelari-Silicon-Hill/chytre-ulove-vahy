Události v období

    Čistá hmotnost vynechává skoky, které způsobil včelař: přidání nebo odebrání nástavku, medobraní, krmení a kontrolu včelstva (změna o 3 kg a víc mezi dvěma měřeními). Zůstane jen to, co udělaly včely: snůška, spotřeba zásob, případně roj. Naměřená data se ukládají beze změny.

    Projekt studentů FEL ČVUT a včelařů Silicon Hill, podpořený z Mikrograntů na podporu trvalé udržitelnosti ČVUT. Zdrojový kód (MIT) Nahrát firmware do váhy API
